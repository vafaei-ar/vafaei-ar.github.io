Alireza Vafaei Sadr, PhD. Assistant Professor, Penn State College of Medicine.

Live website: https://vafaei-ar.github.io/

## About this site

This is a lightweight GitHub Pages site written in HTML, CSS, and vanilla JavaScript. It contains a current academic profile, published research stories with original code-rendered SVG visualizations, selected projects and papers, and an educational AI-SoNar workflow storyboard.

### Sources and research integrity

All numerical results in the interactive figures are transcribed from published aggregate data. See assets/RESEARCH_PROVENANCE.md for references, exact source figures and tables, and interpretation limits.

The Pympute chart is generated by JavaScript from values in assets/research-results.json and includes all 11 methods in the referenced benchmark. The sustainable-AI chart illustrates a published scenario-specific modelled ratio. The ECG and pathomics cards use aggregate published values. No patient-level data are present. The pathology panel is a credited reproduction of previously published real microscopy. The VERA screenshots contain only fabricated example inputs.

The AI-SoNar interaction is a **fictional storyboard**, not a live clinical tool or a validated implementation of the VERA escalation engine.

## Local development

Requires no build tools.

1. Run: python -m http.server 8000
2. Open: http://localhost:8000
3. Run source checks: node scripts/validate_site.cjs
4. Run JavaScript syntax check: node --check assets/research.js

Do not open the HTML as a file URL: browsers can block fetching the JSON data locally.

## Key files

- index.html: site sections and source links
- style.css: base layout
- assets/showcase.css: updated research interface design
- assets/research-results.json: published source values
- assets/research.js: source-backed SVG drawing and fictional check-in scenarios
- assets/RESEARCH_PROVENANCE.md: research figure provenance
- profile-image.jpg: portrait
- assets/media/flash-fig2a-microscopy.png: pixel-preserving crop of published kidney histology + segmentation, licensed CC BY 4.0, credited on the page
- assets/media/flash-fig2-original.png: complete original publisher figure for inspection
- assets/media/vera-setup.png and vera-conversation.png: screenshots rendered from the actual public VERA frontend using only fictional example content
- .qa/download_microscopy.py and .qa/build_vera_screenshots.cjs: scripts used to reproduce these assets

GitHub Pages publishes this site from the main branch. The games and movies pages remain available through links in the footer.
